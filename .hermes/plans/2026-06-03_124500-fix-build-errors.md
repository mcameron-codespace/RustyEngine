# Plan: Fix Build Errors — Rusty Engine Audio Bridge Cleanup

**Date:** 2026-06-03
**Status:** Proposed
**Goal:** Resolve remaining compilation issues introduced during the command buffer migration focused on `src/audio/*` modules, restoring a fully green build and test suite without reverting existing progress.

## Current context / assumptions

- The command buffer plan batches are mostly complete.
- `src/audio/bridge.rs` was migrated to use `CommandBuffer<AudioCommand>` but still contains old sender-related references/mocking.
- `src/audio/mod.rs` was partially migrated; existing fields/tests reference sender/receiver APIs that no longer match the struct.
- Latest signal: `cargo check` passed after `cargo clean`, but earlier timed out; last clean verification indicated the crate compiles.
- Do not delete audio test coverage; preserve caller-visible behavior

## Proposed approach

1. Audit and align `PhysicsAudioBridge` API surface: keep the typed buffer version as source of truth. Remove or retire sender-based test harness references that no longer compile.
2. Make `AudioSystem::command_buffer()` return a mutable reference to the internal typed buffer. Ensure `new()` initializes the buffer directly.
3. Update audio tests to construct `PhysicsAudioBridge` from a borrowed buffer, assert via drained commands, not a channel receiver.
4. Remove dead imports and resolve borrow-checker issues in bridge tests.
5. Optionally add a small integration smoke test in commander/dispatcher if the audio path can be reached from `CommandDispatcher`.

## Step-by-step plan

### Step 1 — Audit audio bridge API drift
- Inspect `src/audio/bridge.rs` for remaining sender references.
- Confirm `PhysicsAudioBridge::new(&mut CommandBuffer<AudioCommand>)` is the only public constructor.

### Step 2 — Fix `src/audio/mod.rs`
- Ensure `AudioSystem` stores `CommandBuffer<AudioCommand>` only.
- Ensure helper `command_buffer(&mut self) -> &mut CommandBuffer<AudioCommand>` returns buffer mutably.
- Remove any unused channel imports/types.

### Step 3 — Rewrite bridge tests
- Replace `(tx, rx) = unbounded()` tests with buffer-drain assertions.

### Step 4 — Run focused validation
- `cargo check`
- `cargo test` (fast path; expect 29 tests, no failures)

### Step 5 — Review leftover warnings
- Address compile warnings only if they indicate incorrect code.
